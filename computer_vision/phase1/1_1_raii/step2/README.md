# Step 2: ピクセルアクセス — `at(x, y)`

## 学習ポイント

- 2次元画像を1次元配列で表現する場合、`y * width + x` でインデックスを計算する（row-major順）。
- 参照 (`&`) を返すことで、読み書き両方に使える関数になる。
- 範囲外アクセスは `std::out_of_range` で安全に処理する。

## row-major インデックス

```
画像 (4x3):
  x→ 0  1  2  3
y=0 [ 0][ 1][ 2][ 3]
y=1 [ 4][ 5][ 6][ 7]
y=2 [ 8][ 9][10][11]

(x=2, y=1) → index = 1*4 + 2 = 6
```

## 参照を返す理由

```cpp
uint8_t& at(int x, int y) { return data_[y * w_ + x]; }
```

`&` を付けて返すことで、呼び出し側で直接書き込める:

```cpp
img.at(2, 1) = 255;              // 書き込み
uint8_t v = img.at(2, 1);        // 読み取り
```

## 問題

`step2.cpp` の `// TODO` 部分に `at(int x, int y)` を実装せよ。

- `data_[y * w_ + x]` への参照 (`uint8_t&`) を返す

### 入出力

**入力:**
```
W H N
op1 x1 y1 [v1]
...
```
- `set x y v`: ピクセル(x,y)にvを書き込む
- `get x y`: ピクセル(x,y)の値を出力

範囲外の場合は `ERR` を出力。

### テスト例

| 入力 | 出力 |
|------|------|
| `4 3 4` / `set 1 2 255` / `set 0 0 128` / `get 1 2` / `get 0 0` | `255` / `128` |
| `2 2 3` / `get 0 0` / `set 5 5 100` / `get 5 5` | `0` / `ERR` / `ERR` |
